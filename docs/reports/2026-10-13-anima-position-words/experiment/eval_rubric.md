# 評価基準

生成画像 1 枚ごとに、次の 6 項目を 0 / 1 で判定する。評価者にはプロンプトの書き方を伏せ、
シーンごとにランダムに割り当てたコード（X1〜X4）だけを見せる。判定に迷ったら厳しい側（0）に倒す。

## キャラクターの見分け方

| キャラ | 外見 | 服装（全シーン固定） |
|---|---|---|
| なつみ | 黒髪の低いポニーテール、ぱっつん前髪、丸眼鏡 | 緑のタートルネックセーター、茶色のロングスカート |
| さやか | 金髪ストレートのロングヘア、おでこ | 赤いパーカー、黒のプリーツスカート |
| あき | 黒髪ボブ、ぱっつん前髪、そばかす、眼鏡なし、平らな胸 | 青い T シャツ、カーキのカーゴパンツ |

## 判定項目

| 項目 | 列名 | 1 にする条件 |
|---|---|---|
| 1 枚の絵 | `single` | 1 枚の連続した絵になっている。左右・上下に別のコマ（枠線や背景の断絶で区切られた別の場面）に分かれていたら 0 |
| 人数 | `count` | 指定した人数ちょうど。余計な人物（背景の通行人など明らかなモブは除く）や欠けがない |
| 属性 | `identity` | 登場すべき各キャラが上表の外見と服装で描かれ、別キャラの髪色・眼鏡・服の色・持ち物が移っていない。全員が該当して 1 |
| 動作 | `action` | シーンの成功の条件にある動作・相互作用が成立し、それぞれ指定したキャラが行っている（役割の入れ替わりは 0） |
| カメラ | `camera` | 指定したカメラ・構図（後ろ姿、俯瞰、オーバーショルダー、ダッチアングル、接写、横からなど）に従っている。指定に反して、人物が横一列に並んでカメラの方を向く絵に引き寄せられていたら 0 |
| 位置 | `position` | **位置グループ（p01〜p04）だけ判定する。** 画面に向かって左・中央・右に、指定どおりのキャラがいる。それ以外のシーンは `-` と書く |

- **成功（`success`）** は判定した項目すべてが 1 のとき 1 とする
- `identity` の服装は「色と種類」で判定する。スカートの丈など形の小さな違いは許容する
- 後ろ姿などで見えない属性（顔のそばかす、眼鏡など）は、見える範囲で矛盾がなければ 1 とする
- ショットサイズの小さな違い（cowboy shot と full body の差など）は `camera` で減点しない。成功の条件が求める構図要素だけを見る
- 人数が違う場合でも、他の項目は描かれた人物から判断できる範囲で判定する（ただし `identity` は原則 0）
- 分割コマの場合、`single` を 0 とし、他の項目はコマをまたいで判断できる範囲で判定する（相互作用はコマをまたいで成立しないので `action` は原則 0）

## 出力形式

CSV。1 行が 1 枚の画像。列は次のとおり。

```
scene,code,seed,single,count,identity,action,camera,position,note
```

`note` には失敗の内容を日本語で短く書く（例: 「左右2コマに分割」「4人出現」「さやかの服が緑」「受け渡しが逆」「正面並び」）。
