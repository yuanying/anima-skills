# 評価基準

生成画像 1 枚ごとに、次の 5 項目を 0 / 1 で判定する。評価者には指示方法の名前を伏せ、
コード（M1〜M9）だけを見せる。判定に迷ったら厳しい側（0）に倒す。

## キャラクターの見分け方

| キャラ | 外見 | 服装（全シーン固定） |
|---|---|---|
| なつみ | 黒髪の低いポニーテール、ぱっつん前髪、丸眼鏡 | 緑のタートルネックセーター、茶色のロングスカート |
| さやか | 金髪ストレートのロングヘア、おでこ | 赤いパーカー、黒のプリーツスカート |
| あき | 黒髪ボブ、ぱっつん前髪、そばかす、眼鏡なし、平らな胸 | 青い T シャツ、カーキのカーゴパンツ |

## 判定項目

| 項目 | 列名 | 1 にする条件 |
|---|---|---|
| 人数 | `count` | 指定した人数ちょうど。余計な人物（背景の通行人など明らかなモブは除く）や欠けがない |
| 属性 | `identity` | 登場すべき各キャラが上表の外見と服装で描かれ、別キャラの髪色・眼鏡・服の色が移っていない。全員が該当して 1 |
| 位置・役割 | `position` | 左右・中央・上下・前後、または「抱える側／抱えられる側」などの役割が指定どおり。全員が該当して 1 |
| ポーズ | `pose` | 各キャラに指定した動作（ピース、腕組み、手を腰など）と持ち物が、指定したキャラに付いている。全員が該当して 1 |
| 構図・相互作用 | `composition` | シーン固有の要求（背中合わせ、肩車、逆さま、俯瞰、煽り、サイズ差、ハイタッチなど）とカメラアングルが成立している |

- **成功（`success`）** は 5 項目すべてが 1 のとき 1 とする
- **スコア（`score`）** は 5 項目の合計（0〜5）とする
- `identity` の服装は「色と種類」で判定する。スカートの丈など形の小さな違いは許容する（色が他キャラのものに変わった、別の服になった、は 0）
- `composition` では、ショットサイズ（`full body` / `cowboy shot` などの画角）の違いは減点しない。各シーンの成功の条件（criteria）が求める構図要素（背中合わせ、肩車、俯瞰、煽り、サイズ差など）とカメラアングルだけを見る
- 人数が違う場合でも、他の項目は描かれた人物から判断できる範囲で判定する（ただし `identity` と `position` は原則 0）
- 指示されたキャラの役割が入れ替わっている（例: 上下が逆の肩車）場合、`position` を 0 にする。`composition` は肩車自体が成立していれば 1 でよい

## 出力形式

CSV。1 行が 1 枚の画像。列は次のとおり。

```
scene,code,seed,count,identity,position,pose,composition,success,score,note
```

`note` には失敗の内容を日本語で短く書く（例: 「4人出現」「さやかの服が緑」「上下逆」）。
